# Nexus Admin

Build a world-class, production-quality Admin Dashboard using Next.js + TypeScript + Tailwind CSS.

The design must look like a premium $100M SaaS product — inspired by the quality of Linear, Stripe, Vercel, Notion, and Apple, but with a unique identity. Avoid generic Bootstrap/admin-template designs.

Layout

Top navigation only — NO left sidebar

Premium logo/brand

Navigation: Dashboard, Properties, Reservations, Customers, Finance, Operations, Reports, AI, Website Builder

Right side: Search, Notifications, Quick Actions, Help, Profile

Sticky/floating top navigation with beautiful hover and active states

CMD/CTRL + K global command palette

Dashboard

Create a stunning executive dashboard with:

Revenue, Occupancy, Reservations, Units and Payment KPIs

Interactive revenue/occupancy charts

Property performance

Revenue breakdown

Recent activity

Notifications and AI insights

Main Modules

Create complete responsive screens for:

Properties

Apartments & Units

Interactive Housing Map

Reservations + Calendar

Customers / CRM

Finance & Payments

Maintenance & Operations

Staff & Tasks

Reports

AI Assistant

Website Builder

Settings

Design

Make it:
Premium, futuristic, minimal, elegant, intelligent and extremely polished.

Use:

Beautiful typography

Excellent spacing

Subtle borders/shadows

Refined colors

Elegant cards

Smooth micro-interactions

Skeleton/loading/empty/error states

Light + Dark mode

Consistent reusable design system

Avoid excessive gradients, excessive rounded cards, clutter and unnecessary animations.

Responsive

Make it truly mobile responsive, not just a scaled desktop version.

Support:

Desktop 1920/1440/1280px

Tablet 1024/768px

Mobile 430/414/390/375/360px

On mobile:

Compact top header + menu

Touch-friendly controls

Responsive cards instead of wide tables

Bottom sheets/drawers where appropriate

Mobile-friendly forms, charts and modals

No horizontal overflow

Quality

Use realistic mock data and make every screen feel functional.

The final result should look like a world-class enterprise SaaS product designed by an elite product design team.

The first impression should be: “WOW, this is insanely good.”
